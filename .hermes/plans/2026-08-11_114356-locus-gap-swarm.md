# Locus — Swarm Implementation Plan (12 gaps, A–L)

> **For Hermes:** this is a PLAN ONLY. Execute with `delegate_task` per task AFTER user approval.
> Plan mode: no code written, no commits, no subagents dispatched yet.

**Goal:** Close the 12 structural gaps (A–L) listed in `docs/FOR_developers-260810.MD` §10 via a coordinated **swarm of leaf subagents**, one per gap, orchestrated by the main Hermes agent — with the orchestrator first verifying **DeepSeek agentic capabilities** (done, see §2).

**Architecture:** The main Hermes agent is the **orchestrator**. Because this deployment has **nesting OFF** (`max_spawn_depth=1`; an `orchestrator` child is forced to `leaf`) and **max 3 concurrent children**, the orchestrator cannot spawn child-of-child agents. Therefore the orchestrator dispatches **12 leaf subagents in waves of ≤3**, one per gap, then consolidates. Each leaf = one gap = isolated, self-contained task.

**Tech stack:** Python 3.11 / 3.13 (repo venv), pytest (offline), DeepSeek V4 (Flash/Pro) via OpenRouter as the agent model.

**Concurrency & file-conflict decision:** leaves run ≤3 at once. Tasks are grouped so that **concurrent leaves never edit the same file**. Gaps sharing a file (e.g. B & J both touch `engine.py`) are sequenced into separate waves or merged into one leaf.
